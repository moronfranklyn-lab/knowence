数据不出内网

平台节点负责检索与治理，推理节点负责生成，两者都在你的内网里。 对话、向量、重排三类模型可以全部本地部署，没有一条请求发往外部服务。

想先用云端跑起来也行。把 compose 里两个本地模型服务注释掉即可，平台功能不受影响。

三步跑起来

需要 Docker。本地模型走国内镜像源下载，约 2.2GB。

  1. 取代码，填三个密钥 数据库密码、JWT 密钥、加密密钥。没填会直接报错拦下来。 
    git clone https://github.com/moronfranklyn-lab/knowence.git
cd knowence && cp .env.example .env
  2. 下载本地模型 脚本会把模型直接放进 Docker 原生卷。放到宿主机目录再挂进去会慢 9 倍。 
    ./scripts/download-models.sh
  3. 启动 首次启动要等数据库迁移和模型加载，重排模型大约 45 秒。 
    docker compose up -d
# 打开 http://localhost:8081
