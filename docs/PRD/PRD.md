# 知微 Knowence · 企业 AI 工作系统 — PRD

> 版本：v0.1（阶段 0 草稿）｜日期：2026-09-29
> 状态：待评审。文中标「假设」的条目需产品负责人逐条确认或修正。
> 本 PRD 描述通用产品形态，不绑定任何具体企业客户数据。

## 1. 目标用户与核心任务

**产品定位**：面向企业的私有化 AI 工作系统。企业放入自己的资料，即可获得带出处的知识问答、多步骤任务执行与渠道分发能力；AI 能力按角色分级开放。

| 角色 | 场景 | 核心任务 |
| --- | --- | --- |
| 一线客服/销售 | 日常业务查询 | 用自然语言查商品/套餐/政策类问题，拿到有原文引用的答案 |
| 职能岗（采购/财务/HR） | 制度与单据处理 | 查内部制度、流程口径；跨部门数据互相不可见 |
| 部门主管 | 审批与监督 | 审批高风险 AI 操作；查看本部门使用与审计记录 |
| 平台管理员 | 治理 | 配置模型、分空间放资料、定角色权限、管成本 |

**北极星用法**：员工在 IM 或网页提问 → 系统在"该员工可见的知识范围"内检索 → 返回带引用的答案；置信度不足时按规则转人工。

## 2. 输入、过程和产物

- **输入**：企业资料（合同、制度、商品目录、FAQ、话术库等，Word/PDF/Excel/Markdown）；员工的自然语言问题或任务指令；各模型服务的 API Key。
- **过程要看到**：检索命中了哪些文档片段、答案的每一句对应哪条引用、Agent 每一步在做什么（可中断）、被权限拦截的请求是谁拦的、为什么。
- **产物**：带引用的回答；生成的文件（报告/表格/文档）；任务执行记录；审计日志。
- **长期保留**：知识库内容与分块版本、对话与任务历史、审计日志、Prompt/模型的沙箱验证记录。

## 3. Agent 的主链路

- 简单查询：RAG 直答（检索→生成→附引用），一轮完成。
- 多步任务：Agent 模式（规划→逐步调用工具→交付），关键步骤展示进度，允许中断补充。
- **必须人工确认才能继续的动作**（白名单制，其余默认放开）：删除/覆盖知识库内容、对外发送消息或邮件、涉及个人信息的批量导出、切换生产环境的模型或 Prompt。
- 人机协同规则：AI 置信度高→直接回答；低→转人工并附已检索材料；命中敏感类别（个人信息、合规、资金）→强制人工兜底。

## 4. 什么算"生成得好"

- 答案的每一条事实性结论都有可点开的原文出处；无出处时必须明说"知识库未覆盖"，不许编。
- 权限正确的回答才算对的回答：越权请求必须被拒且留痕，宁可不答不可错答。
- 允许的瑕疵：引用排序不完美、个别措辞生硬。
- 判定方式：上线前用 5–10 条真实业务问题做样例打分（由业务负责人评），据此定量化口径；上线后以抽检+转人工率持续评估。

## 5. 交付阶段与优先级

**MVP（第一版，只含四件事）**：
1. 上传资料→自动解析/分块/向量化→建库；
2. 混合检索 + Rerank + 引用溯源的问答；
3. 最小 RBAC：空间隔离 + 至少两级角色 + 基础审计日志；
4. 模型层接 OpenAI 兼容 API（云端），支持一键指向本地推理服务（仅打通链路，不承诺性能）。

**第二版**：Agent 任务模式与沙箱、IM 渠道接入（企微/飞书）、置信度分流转人工、评测集与质量看板。
**暂缓**：外部互联网渠道接入、复杂 BI 报表、移动端原生 App。

## 6. 模型与成本约束

- 对话/embedding/rerank 三类模型独立可配；厂商不设限，默认要求 OpenAI 兼容接口。
- 合规方向：**支持全栈私有化**——模型可换成本地部署的开源模型（如 Qwen 系 + vLLM/Ollama），业务数据不出企业内网。
- 成本要求：按空间/按人统计 token 用量与费用，可设上限告警。单次问答成本目标量级：≤0.05 元（假设，待定）。

## 7. 数据与非功能要求

- 数据边界：合同、人事、号卡/用户信息等视为敏感数据；禁止流向会用于训练的外部服务；隐私字段不落明文日志。
- 预计规模（假设）：试点 30–50 人，目标 200–500 人；并发问答 ≤20 QPS；单文档 ≤50 MB。
- 响应时间（假设）：RAG 首字 ≤3s，完整答案 ≤15s。
- 可用性：任务状态持久化，进程重启可续跑；重要业务数据不只在内存。
- 数据存放：境内/企业自有服务器。

## 8. 上线与账号

- 先内部试用；登录对接企业身份源（企微/飞书扫码或 LDAP/SSO），不做独立注册。
- 部署形态：企业自有服务器/内网，docker-compose 起步。
- 云费用预算：不适用（私有化为主）；若用云端 API 过渡，月预算上限待定。
